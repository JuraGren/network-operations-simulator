# Тестові сценарії для сервісу «Реєстр пристроїв» (Team 1)

## Тест 1: Успішне додавання пристрою (Позитивний)
- **Вхідні дані**: ID = 1, Name = "Router-1", Type = "ROUTER", Status = 1 (ONLINE).
- **Очікуваний результат**: Пристрій успішно додано до масиву.

## Тест 2: Заборонa дубліката ID (Негативний)
- **Вхідні дані**: Додавання пристрою з ID = 1, коли пристрій з ID = 1 вже існує.
- **Очікуваний результат**: Повідомлення про помилку валідації (дублікат ID).

## Тест 3: Некоректний тип пристрою (Негативний)
- **Вхідні дані**: ID = 2, Name = "Switch-1", Type = "SWITCH", Status = 1.
- **Очікуваний результат**: Повідомлення про некоректний тип пристрою.

## Тест 4: Зміна стану пристрою
- **Вхідні дані**: Зміна стану пристрою ID = 1 з ONLINE (1) на OFFLINE (0).
- **Очікуваний результат**: Стан пристрою оновлено на OFFLINE.

## Тест 5: Пошук неіснуючого пристрою
- **Вхідні дані**: Пошук пристрою з ID = 999.
- **Очікуваний результат**: Повідомлення "Пристрій з ID 999 не знайдено".
